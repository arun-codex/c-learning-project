# Contributing

Thanks for considering a contribution to this C learning repository.

## Good first contributions
- Fix a typo or incorrect explanation in the learning notes.
- Add a small, tested C example that matches the chapter topic.
- Improve compilation instructions for GCC or Clang.
- Add input/output examples and edge cases to existing exercises.
- Clarify a concept without copying copyrighted course material.

## Contribution workflow
1. Open an issue describing the problem or proposed lesson improvement.
2. Fork the repository and create a focused branch.
3. Make one small change and compile/test any C code.
4. Explain what changed and how you tested it.
5. Open a pull request linked to the issue.

## C code checklist
- Compile with warnings enabled, for example: `gcc -Wall -Wextra -Wpedantic example.c -o example`.
- Include expected input and output where useful.
- Handle invalid input when it is relevant to the exercise.
- Keep examples beginner-friendly and explain non-obvious behavior.

Please only claim testing that you actually performed.
